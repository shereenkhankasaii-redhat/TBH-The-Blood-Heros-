# TBH - The Blood Heroes 🩸

A full-stack blood donation management system that connects blood donors, patients, hospitals, and attendants.

## Features
- Donor registration and management
- Patient blood requests
- Hospital dashboard
- Real-time notifications
- Reports and analytics

## Tech Stack
- Next.js
- TypeScript
- Drizzle ORM
- PostgreSQL (Neon)
- Tailwind CSS

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Set up your `.env` file with database credentials
4. Run `npm run dev`
